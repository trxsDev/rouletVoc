# 🎡 RouletVoc • AR Hand Gesture Vocabulary Game

เกมจับคู่คำศัพท์และฝึกท่าทางมือผ่านกล้อง AR (Augmented Reality) แบบเรียลไทม์ ขับเคลื่อนด้วย **MediaPipe Tasks HandLandmarker** และ **Pygame**

---

## 🌟 ฟีเจอร์เด่น (Key Features)

- 🖐️ **Real-time AI Hand Tracking**: ตรวจจับมือและโครงกระดูก 21 จุด (Landmarks Skeleton) แสดงผลเป็นเส้นไซเบอร์เนติกส์นีออน
- 🎡 **4-Sector Gesture Roulette Wheel**: วงล้อสุ่ม 4 ท่าทางมือ (`PINCH`, `FIST`, `PEACE`, `PALM`) พร้อมฟิสิกส์การหมุนและเข็มชี้แบบ 3D
- 🛡️ **CTO-Grade Biometric Engine**: ระบบวิเคราะห์สัดส่วนข้อนิ้ว 3D ป้องกัน False Positive และมี **Action Lock-on Charge Meter** (~0.2s) ยืนยันความตั้งใจของผู้เล่น
- 📚 **12 Classroom Vocabulary Items**: กราฟิก 3 มิติความละเอียดสูง (สมุด, หนังสือ, ปากกา, ดินสอ, ยางลบ, ไม้บรรทัด, โต๊ะ, เก้าอี้, หน้าต่าง, พัดลม, นาฬิกา, กระเป๋า)
- 🔊 **7 Arcade Sound FX Engine**: ระบบเสียงเอฟเฟกต์แบบ Low-latency สำหรับการหมุนวงล้อ, นับถอยหลัง 3-2-1, ล็อคเป้าหมาย, เลือกถูก (+100) และเลือกผิด

## 🎮 กติกาการเล่น (How to Play)

1. **หมุนวงล้อสุ่มท่าทาง**: วงล้อจะสุ่มท่าทางที่ต้องใช้ในรอบนั้น (`จีบนิ้ว`, `กำมือ`, `ชู 2 นิ้ว`, หรือ `แบมือ`)
2. **จดจำการ์ด (Memorize)**: ดูตำแหน่งการ์ด 6 ใบที่มีภาพและคำศัพท์ภาษาไทย-อังกฤษ เป็นเวลา 3.5 วินาที
3. **นับถอยหลัง (3.. 2.. 1..)**: เตรียมพร้อมเมื่อการ์ดปิดลง
4. **ค้นหาและปลดล็อค (Play)**: 
   - เลื่อนมือเพื่อบังคับ Cursor ไปยังการ์ดคำศัพท์เป้าหมาย
   - ทำท่าทางที่วงล้อสุ่มได้ค้างไว้จน **แถบชาร์จสีเขียวนีออน (Action Charge Meter)** เต็มหลอดเพื่อเปิดการ์ด!
